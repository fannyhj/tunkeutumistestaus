


Loin VirtualBoxiin Host-only-verkon Kalin ja Metasploitable 2:n välistä liikennettä varten. Host-only-verkon avulla virtuaalikoneet voivat kommunikoida 
keskenään ilman, että Metasploitable tarvitsee yhteyttä Internetiin.


<img width="890" height="110" alt="image" src="https://github.com/user-attachments/assets/847c98cd-3000-4171-be53-309f3efb8bed" />


Kalille määritin ensimmäiseksi verkkosovittimeksi NAT-sovittimen. NAT-yhteyden avulla Kali voi tarvittaessa muodostaa yhteyden Internetiin esimerkiksi
ohjelmistojen asentamista varten.

<img width="560" height="321" alt="image" src="https://github.com/user-attachments/assets/2056d046-c2a5-4665-8a70-cf426963c3e8" />


Kalin toiseksi verkkosovittimeksi määritin Host-only Adapterin. Tätä verkkosovitinta käytetään Kalin ja Metasploitablen väliseen eristettyyn 
laboratorioverkkoon.


<img width="555" height="295" alt="image" src="https://github.com/user-attachments/assets/71f94334-a71c-4fe5-afed-56ebdbf975d3" />


Metasploitablelle määritin ainoastaan Host-only-verkkosovittimen. Kali ja Metasploitable käyttävät samaa Host-only-verkkoa. Metasploitablella ei ole 
NAT-verkkosovitinta, joten se on eristetty Internetistä.


<img width="565" height="268" alt="image" src="https://github.com/user-attachments/assets/85398b33-371c-4516-8761-3bdfca61c491" />


Määritin Kalin Host-only-verkkoliitännälle eth1 staattisen IPv4-osoitteen 192.168.56.10/24. Verkkoliitäntä otettiin käyttöön ip link -komennolla.

Komennot:

sudo ip addr add 192.168.56.10/24 dev eth1

sudo ip link set eth1 up

ip addr show eth1

<img width="621" height="129" alt="image" src="https://github.com/user-attachments/assets/59fb625f-3880-4c7b-b4dc-c10983b914a3" />

Määritin Metasploitablen eth0-verkkoliitännälle osoitteen 192.168.56.20 ja aliverkon peitteeksi 255.255.255.0. Kali ja Metasploitable ovat näin 
samassa 192.168.56.0/24-verkossa.

Komennot:

sudo ifconfig eth0 192.168.56.20 netmask 255.255.255.0 up

ifconfig eth0

<img width="715" height="176" alt="image" src="https://github.com/user-attachments/assets/b9a5b4e6-101f-48a4-bafd-82bdb4c19770" />

Tarkistin Kalin reititystaulun komennolla ip route. NAT-verkon oletusreitti kulkee eth0-liitännän kautta, kun taas laboratorioverkko 
192.168.56.0/24 käyttää Host-only-liitäntää eth1.

<img width="597" height="141" alt="image" src="https://github.com/user-attachments/assets/16804ac4-de4e-46f4-ac53-33da68daef72" />

Testasin Kalin ja Metasploitablen välisen verkkoyhteyden pingillä. Metasploitable vastasi Kalin lähettämiin paketteihin, 
joten Host-only-verkon toiminta varmistui.

<img width="572" height="198" alt="image" src="https://github.com/user-attachments/assets/0a1f3328-7a43-4957-a332-50de4013b3cd" />

Testasin yhteyttä lisäksi Nmapilla. Suoritin Metasploitablea vastaan komennon nmap -sC 192.168.56.20. Parametri -sC suorittaa Nmapin oletusskriptit. Skannaus onnistui ja Metasploitablen tarjoamia palveluita löytyi. Kaikki ei mahtunut screenshottiin tietenkään.

Komento: nmap -sC 192.168.56.20

<img width="633" height="525" alt="image" src="https://github.com/user-attachments/assets/08874f4c-137d-4f35-ba77-ea1e854a3e0d" />


Porttiskannauksen ajaksi irrotin Kalin NAT-verkkosovittimen virtuaalisen verkkokaapelin. Host-only-verkkosovitin jätettiin käyttöön. Näin laboratorioympäristö voidaan eristää Internetistä porttiskannauksen ajaksi.

ip route, NAT poistui
