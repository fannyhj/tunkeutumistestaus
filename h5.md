# h5 Elokuu2026!

Tämä on tehtäväraportti Tero Karvisen Tunkeutumistestaus-kurssille (ICI005AS3A-3007). Tehtävänannoissa on hyödynnetty Tero Karvisen Tunkeutumistestaus-läksysivuilla annettuja ohjeita. (Karvinen 2026)

## Lue/katso ja tiivistä.

## Karvinen 2022: Cracking Passwords with Hashcat

- Järjestelmät eivät säilytä alkuperäisiä salasanoja. Niiden sijaan ne säilytttävät hasheja.
- Hashit ovat muodossa: "f2477a144dff4f216ab81f2ac3e3207d".
- Salasanojen murrossa on hyvä käyttää sanakirjoja jotka sisältävät yleisiä salasanoja. Suosituin sanakirja on Rockyou.
- Hashcatin täytyy tietää hashin tyyppi sen murtaakseen.

(Karvinen 2022)

## a) Asenna Hashcat ja testaa sen toiminta murtamalla esimerkkisalasana.

Ensimmäiseksi päivitin virtuaalikoneeni ja asensin hashcatin komennoilla:

$ sudo apt-get update

$ sudo apt-get -y install hashid hashcat wget

Tämä olikin jo asennettuna niin tässä ei tapahtunutkaan muutoksia.

Seuraavaksi loin kansion hashed ja siirryin sinne komennoilla:

$ mkdir hashed

$ cd hashed

Sitten latasin rockyou.txt sanakirjan. Rockyou on suosituin tunnettu salasanalista, joka sisältää yli 14 miljoonaa vuotanutta käyttäjätunnusten salasanaa. (Hackerdna 2026)

Löysin komennot Tero Karvisen sivuilta "Cracking Passwords with Hashcat". (Karvinen 2022)

$ wget https://github.com/danielmiessler/SecLists/raw/master/Passwords/Leaked-Databases/rockyou.txt.tar.gz

$ tar xf rockyou.txt.tar.gz

$ rm rockyou.txt.tar.gz

Käytetyt komennot liittyvät pakatun tiedoston purkamiseen ja sen jälkeen paketin poistamiseen.

Käytin seuraavaksi alla olevaa komentoa, jolla tunnistaan tiivisteen mahdollinen tyyppi ja sitä vastaava Hashcat mode -numero:

$ hashid -m 6b1628b016dff46e6fa35684be6acc96

<img width="472" height="403" alt="image" src="https://github.com/user-attachments/assets/a9614aa6-6221-4b20-946e-b11555463b94" />

Seuraavaksi yritin murtaa MD5-tiivisteen sanakirjahyökkäyksellä. Hashcat kokeili rockyou.txt-tiedostossa olevia salasanoja ja vertasi niiden MD5-tiivisteitä annettuun tiivisteeseen. Mahdollinen löytynyt ratkaisu tallennettiin solved-tiedostoon.

$ hashcat -m 0 '6b1628b016dff46e6fa35684be6acc96' rockyou.txt -o solved

hashcat – Hashien eli tiivisteiden murtamiseen tarkoitettu ohjelma, jonka juuri asensimme.

-m 0 – Määrittää hashin tyypin. Numero saadaan esimerkiksi hashid-komennolla tai komennolla hashcat --example-hashes.

'6b1628b016dff46e6fa35684be6acc96' – Hash eli tiiviste, jonka haluamme murtaa.

-o solved – Tallentaa löydetyn ratkaisun selväkielisenä nykyiseen työhakemistoon uuteen solved-nimiseen tiedostoon.

(Karvinen 2022)

Lataus onnistui, joka jälkeen yritin käyttää aikaisempaa komentoa uudestaan.

## c) Asenna John the Ripper ja testaa sen toiminta murtamalla jonkin esimerkkitiedoston salasana.

Latasin John the Ripperiin tarvittavat työkalut Tero Karvisen ohjeiden "Crack File Password With John" mukaisesti. (Karvinen 2023)

$ sudo apt-get -y install micro bash-completion git build-essential libssl-dev zlib1g zlib1g-dev zlib-gst libbz2-1.0 libbz2-dev atool zip wget

## e) Tiedosto. Tee itse tai etsi verkosta jokin salakirjoitettu tiedosto, jonka saat auki. Murra sen salaus. (Jokin muu formaatti kuin aiemmissa alakohdissa kokeilemasi).

Tein omalla host-koneellani Word-tiedoston ja tallensin sen pdf-muotoon. Pudotin tiedoston sitten virtuaalikoneeseni.

Seurasin tästä eteenpäin aikaisemman opiskelijan GitHub -julkaisua apunani. Opiskelijan käyttäjänimi GitHubissa on Veitim ja julkaisun nimi on "h4 Leviämässä". (Veitim 2025)

Käytin raporttia oheten komentoa:

$ qpdf --encrypt salasana salasana 256 -- sala.pdf salattu.pdf

## h) Hash rules. Näytä esimerkki HashCatin sääntöjen käytöstä (rules).

Tein oman sanakirjan, joka sisälsi sanan winnie komennolla:

$ echo "winnie" > sanat.txt

Tämän jälkeen tein Hashcatille säännön $1$2$3, joka lisää sanan loppuun merkit 123.

$ echo '$1$2$3' > oma.rule

Eli:

winnie

muuttuu Hashcatin käsittelyssä:

winnie123

Testasin sääntöä komennolla

$ hashcat --stdout sanat.txt -r oma.rule

<img width="366" height="68" alt="image" src="https://github.com/user-attachments/assets/7dfc5201-c8e3-4edc-9b0c-e7b727c4a6d8" />

Hashcat muodosti siis sanasta winnie uuden salasanaehdokkaan winnie123. Rules-toiminnon avulla sanakirjan sanoista voidaan siis muodostaa automaattisesti erilaisia muunnelmia ilman, että jokaista vaihtoehtoa tarvitsee lisätä sanakirjaan erikseen.
