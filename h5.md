## Karvinen 2022: Cracking Passwords with Hashcat

- Järjestelmät eivät säilytä alkuperäisiä salasanoja. Niiden sijaan ne säilytttävät hasheja.
- Hashit ovat muodossa: "f2477a144dff4f216ab81f2ac3e3207d".
- Salasanojen murrossa on hyvä käyttää sanakirjoja jotka sisältävät yleisiä salasanoja. Suosituin sanakirja on Rockyou.
- Hashcatin täytyy tietää hashin tyyppi sen murtaakseen.

$ mkdir hashed
$ cd hashed

$ wget https://github.com/danielmiessler/SecLists/raw/master/Passwords/Leaked-Databases/rockyou.txt.tar.gz
$ tar xf rockyou.txt.tar.gz
$ rm rockyou.txt.tar.gz

Nämä liittyvät pakatun tiedoston purkamiseen ja sen jälkeen paketin poistamiseen:

tar xf rockyou.txt.tar.gz → purkaa rockyou.txt.tar.gz-arkiston nykyiseen kansioon.
tar = arkistojen käsittelyyn käytettävä ohjelma
x = extract eli pura
f = seuraavaksi annetaan käsiteltävän tiedoston nimi
Lopputuloksena saat esimerkiksi rockyou.txt-tiedoston.
rm rockyou.txt.tar.gz → poistaa alkuperäisen pakatun tiedoston purkamisen jälkeen.
rm = remove eli poista

$ hashcat -m 0 '6b1628b016dff46e6fa35684be6acc96' rockyou.txt -o solved

hashcat	the hash cracking program we just installed
-m 0	type of the hash, the number we obtained from 'hashid' or 'hashcat --example-hashes'
'6b1628b016dff46e6fa35684be6acc96'	the hash we want to crack. Put single quotes around it, as many hashes contain special characters.
-o solved	save the solution as plain text to a new file "solved" in working directory
